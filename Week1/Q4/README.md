# 問4｜sync パッケージの応用（sync.Once / sync.Map）

## 目標
`sync.WaitGroup` や `sync.Mutex` に続いて、`sync.Once`（1回限りの実行保証）と `sync.Map`（並行安全なマップ）の使い方を学びます。

## 今回の演習で学ぶこと
この問題では、並行処理における「1度限りの実行」と「安全なデータ共有」を、以下の3つの重要ポイントに注目して学びます。

**1. sync.Once：「初期化は1度だけ」の実装**
複数の作業員（ゴルーチン）が同時に「準備ボタン」を押したとしても、実際の準備作業（特定の処理）を**全システム上で絶対に1回しか実行させない**ための強力な仕組みです。
```go
var once sync.Once
once.Do(func() {
    fmt.Println("初期化完了！")
})
```
- `var once sync.Once`: 1回きりの実行を管理する番人を用意します。
- `once.Do(func() {...})`: この中に書かれた関数は、何千回呼ばれようと最初の1回しか実行されません。データベースの接続設定や、重たい設定ファイルの読み込みなどに必須の技術です。

**2. sync.Map：並行安全なマップへの書き込み**
通常の `map`（辞書）は、複数のゴルーチンが同時に書き変えようとするとデータが壊れてパニック（強制終了）を起こします。それを防ぐのが並行安全な `sync.Map` です。
```go
var sm sync.Map
sm.Store("key", "value") // データの保存
```
- `var sm sync.Map`: 鍵をかけなくても安全に複数人で読み書きできる特殊な金庫（マップ）を作ります。
- `sm.Store(...)`: 通常の `map["key"] = "value"` の代わりに、専用の `Store` メソッドを使ってデータを安全に預けます。

**3. sync.Map からの読み出しと型アサーション**
安全な金庫からデータを取り出し、元の形に戻して使う手順です。
```go
if v, ok := sm.Load("key"); ok {
    str := v.(string) // 型アサーション
}
```
- `sm.Load("key")`: キーを指定してデータを取り出します。`ok` が true なら存在した証拠です。
- `v.(string)`: `sync.Map` から出てくるデータは全て「正体不明の箱（`any`型）」に入っているため、「これは文字列（`string`）ですよ」と型アサーションで明示してあげる必要があります。




**sync.Map の使い分け**
読み込みが圧倒的に多く、書き込みがたまにしか発生しないケースや、各ゴルーチンが別々のキーを頻繁に触るようなケースで最大のパフォーマンスを発揮します。

## 問題文
`main.go` の `___` の部分を埋めてプログラムを完成させてください。

1. `sync.Once` を使って `initialize()` 関数が10ゴルーチンから呼ばれても1回だけ実行されるようにしてください。
2. `sync.Map` の `sm` を使い、各ゴルーチンから安全にデータを `Store` してください。
3. `sm.Load(key)` でデータを取り出してください。
